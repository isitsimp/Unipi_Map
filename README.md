# Unipi_Map
Εθελοντικό project στα πλαίσια του μαθήματος Δικτυακά Πληροφοριακά Συστήματα, για την βελτιστοποίηση των ηλεκτρονικών υπηρεσιών του τμήματος Ψηφιακών Συστημάτων του Πανεπιστημίου Πειραιώς.
Δημιουργία διαδραστικού χάρτη για τα κτίρια του πανεπιστημίου και τις στάσεις ΜΜΜ κοντά σε αυτά

Εργαλεία: OpenStreetMap για την δημιουργία του χάρτη, βιβλιοθήκη Leaflet για την αναπαράσταση των πινεζών και πληροφοριών, Google Maps για την καθοδήγηση

Πόροι: https://leafletjs.com/examples.html (δημιουργία πινεζών)
https://fontawesome.com/ (διάφορα εικονίδια)
Stitch AI (δημιουργία dropdown menu)

UI/Χρήση: 
Μενού με το λογότυπο του πανεπιστημίου με σύνδεσμο στην αρχική ιστοσελίδα των Ψηφιακών Συστημάτων και κατάλογος με τα κτήρια της σχολής με στνδέσμους. Κουμπιά ελέγχου μεγένθυση-σμύκρινση, επιλογή εμφάνισης στάσεων/κτιρίων και εύσημα στον δημιουργό του Leaflet και πνευματική ιδιοκτησία OpenStreetMap.
Οι Πινέζες, εμφανίζουν διαφορές πληροφορίες. Για κτίρια: Τίτλος κτιρίου, διεύθυνση, φωτογραφία, πληροφορίες (πχ ωράριο λειτουργίας), εικονίδιο για το αν είναι προσβάσιμο με αναπηρικό αμαξίδιο ή όχι και link για googlemaps και streetview. Για στάσεις: Όνομα στάσης, τύπος (λεωφορείο/τραμ/μετρό αντίστοιχες πινέζες) / ποια λεωφορεία περνάνε και link για googlemaps και streetview.

Δομή: 
Φάκελοι: buildingsPNGS για εικόνες κτηρίων, images για εικονίδια και fonts για γραμματοσειρά
Αρχεία: html,css,js, buildings.json και stops.json

Αρχεία:
buildings.json: Πληροφορίες για τα κτήρια του Πανεπιστημίου
stops.json: Πληροφορίες για τις κοντινότερες στάσεις του Πανεπιστημίου 
unipi_map.css: Υπεύθυνο για την εμφάνιση της ιστοσελίδας 
unipi_map.html: Υπεύθυνο για την ύπαρξη του χάρτη
unipi_map.js: Υπεύθυνο για την λειτουργία της ιστοσελίδας

Επόμενο βήμα: Μετάφραση στα Αγγλικά
