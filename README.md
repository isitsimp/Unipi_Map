# Unipi_Map
Εθελοντικό project στα πλαίσια του μαθήματος Δικτυακά Πληροφοριακά Συστήματα, για την βελτιστοποίηση των ηλεκτρονικών υπηρεσιών του τμήματος Ψηφιακών Συστημάτων του Πανεπιστημίου Πειραιώς.
Δημιουργία διαδραστικού χάρτη για τα κτίρια του πανεπιστημίου και τις στάσεις ΜΜΜ κοντά σε αυτά

Εργαλεία: OpenStreetMap για την δημιουργία του χάρτη, βιβλιοθήκη Leaflet για την αναπαράσταση των πινεζών και πληροφοριών, Google Maps για την καθοδήγηση

Πόροι: https://leafletjs.com/examples.html (δημιουργία πινεζών)
https://fontawesome.com/ (διάφορα εικονίδια)

UI/Χρήση: 
(Πάνω αριστερά) Μενού με το λογότυπο του πανεπιστημίου και σύνδεσμοι στις αρχικές ιστοσελίδες του ΠαΠει και των Ψηφιακών Συστημάτων. (Κάτω αριστερά) κουμπιά ελέγχου μεγένθυση-σμύκρινση. (Πάνω αριστερά) επιλογή εμφάνισης στάσεων/κτιρίων. 
(Κάτω αριστερά) Αλλαγή γλώσσας (υπό κατασκευή), εύσημα στον δημιουργό του Leaflet και πνευματική ιδιοκτησία OpenStreetMap. Πινέζες, εμφανίζουν διαφορές πληροφορίες. Για κτίρια: Τίτλος κτιρίου, διεύθυνση, φωτογραφία, πληροφορίες (πχ ωράριο λειτουργίας), εικονίδιο για το αν είναι προσβάσιμο με αναπηρικό αμαξίδιο ή όχι και link για googlemaps και streetview. Για στάσεις: Όνομα στάσης, τύπος (λεωφορείο/τραμ/μετρό αντίστοιχες πινέζες) / ποια λεωφορεία περνάνε και link για googlemaps και streetview.

Δομή: 
Φάκελοι: buildingsPNGS για εικόνες κτηρίων, images για εικονίδια και fonts για γραμματοσειρά, Αρχεία: html,css,js, buildings.json και stops.json

Αρχεία:
buildings.json: Πληροφορίες για τα κτήρια του Πανεπιστημίου
stops.json: Πληροφορίες για τις κοντινότερες στάσεις του Πανεπιστημίου 
unipi_map.css: Υπεύθυνο για την εμφάνιση της ιστοσελίδας 
unipi_map.html: Υπεύθυνο για την ύπαρξη του χάρτη
unipi_map.js: Υπεύθυνο για την λειτουργία της ιστοσελίδας

Επόμενο βήμα: Μετάφραση στα Αγγλικά
